# 商家演示与试点交接

当前可交付本地演示：帮助摄影店发布活动、收集预约和管理状态；帮助餐饮店发布优惠、限量发券并一次性核销。它支持两个独立商家、真实密码登录与服务端权限控制，不包含实际收款、点餐、外卖或自动社媒发布。

## 建议演示顺序

| 步骤 | 展示重点 |
| --- | --- |
| 首页与双行业页面 | 移动端顾客体验、演示内容标记 |
| 店主工作台 | 店铺资料、活动和真实事件统计 |
| 活动编辑 | 素材上传、规则、离线文案建议、人工审核 |
| 摄影流程 | 提交预约、名额变化、店主确认 |
| 餐饮流程 | 顾客领券、店员核销、重复核销拒绝 |
| 渠道与隐私 | 来源链接、二维码、凭证查询与资料删除 |

本地二维码指向本机地址，其他手机无法直接访问本机回环地址。手机布局可在本机浏览器移动视图中演示；真正跨设备试点需要先完成可访问环境部署。

## 试点前收集的信息

商家名称、行业、联系人、场地地址、品牌色与已获授权素材；实际活动时间、价格、规则、摄影档期或优惠券额度；参与店员、支持负责人和数据处理联系渠道。逐项让商家确认展示信息，不能把演示素材当作真实案例。

确认试点范围、服务期限、修改次数、支持方式、交付验收和费用后再实施。PRD 中的 399 元/店是待验证报价假设；商户访谈、真实付费与续用均未在本次开发交付中发生或验证。

## 当前验收依据

已提供本地源代码、锁定依赖、迁移、启动入口、操作/部署/安全/API 文档，以及测试日志和截图。验证项目与结果以 [TEST_REPORT.md](TEST_REPORT.md) 为准。

正式商用仍需完成云部署、真实账户与密钥、真实模型服务验证（若启用）、适用业务规则与素材确认、备份监控及实际商户验收。当前不能承诺营收提升、转化保证或已完成 CloudBase/RLS 集成。

记录试点反馈时区分：页面是否易用、业务是否跑通、数据是否可信、商家是否愿意付费。使用商家实际数据形成报告，演示点击和测试预约不计为真实业务成果。
