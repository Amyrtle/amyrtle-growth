# Amyrtle Growth｜研发验收与真实客户上线闸门

## P0 必测列表

- [ ] T01 未登录不能访问商家后台或私有 API。
- [ ] T02 店铺 A 的 Owner/Staff 无法读写店铺 B 的活动、预约、券和报表。
- [ ] T03 草稿和下线活动的 URL 不公开。
- [ ] T04 AI 虚构优惠/客户评价的内容不能自动发布。
- [ ] T05 2 个并发请求抢摄影最后 1 位，仅成功 1 单。
- [ ] T06 预约请求重试不产生重复预约记录。
- [ ] T07 同一券并发核销仅有 1 次成功。
- [ ] T08 已过期/他店/已用券无法核销。
- [ ] T09 非法价格、非法时段、XSS、超长输入得到安全拒绝。
- [ ] T10 AI API 超时/断开时仍能手动编辑并发布活动。
- [ ] T11 真实预约、领取、核销引发准确事件统计，假数据不作为真实收入。
- [ ] T12 访客数据访问/删除请求有可执行流程。
- [ ] T13 375px 手机端可顺利走完行业主流程，无横向溢出。
- [ ] T14 部署具有可执行回滚及备份恢复操作说明。

## 真实客户上线前人工审批

- [ ] 已确认经营主体与域名/备案/必要资质。
- [ ] 已验证隐私告知、联系方式、数据删除路径。
- [ ] 云端数据库访问规则已实测，没有匿名管理权限。
- [ ] 模型 token、存储和云账单已设预算/告警。
- [ ] 生产环境发布和可能产生费用已经获得本人授权。
- [ ] 服务报价、售后范围、商家图片使用权限已明确。
